## Design Context

### Users

Студенты и абитуриенты Московского Политеха. Быстрый поиск ответа с телефона между парами; спокойное чтение инструкций с компьютера. Участники дополняют материалы через GitHub.

### Brand Personality

Прямой, энергичный, заботливый. Тексты без бюрократии и выдуманных обещаний.

### Aesthetic Direction

Ориентир пользователя — mospolytech.ru: точная палитра #1e1e1e / #ffffff / #e63246 / #bcbcbc / #393939, контрастная типографика, линии и спиральная графика. Тёмная тема по умолчанию, светлая по переключателю. Первый экран — просторная поисковая сцена без вступительного заголовка: текстовый логотип в углу, одинаковые круглые кнопки поиска/темы/GitHub/меню справа на всех страницах, четыре ссылки вокруг поля. Самостоятельные завитки с градиентом прозрачности плавно прорисовываются; тонкие рёбра добавляют глубину. Меню — компактные кнопки в два столбца. Прозрачный favicon — вопрос из точек и прыгающий шарик. При прокрутке поле компактно закрепляется сверху, графика и ссылки уходят. Ниже — категории, теги и плоский список статей с источниками. На телефоне ссылки занимают устойчивые позиции; движение не мешает нажатию. Футер приглашает дополнять справочник. Самостоятельный неофициальный проект, без имитации официального статуса.

### Design Principles

- Поиск и полезные переходы раньше декора.
- Источники и статус проверки рядом с материалом.
- Читаемая кириллица, короткие строки, большой контраст размеров.
- Полная функциональность на 320 px, клавиатуре и reduced motion.
- Согласованные появления, движение карточек, подсветка под курсором и переходы. Без тяжёлого фона; reduced motion отключает движение.
