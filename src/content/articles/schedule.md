## Куда открыть

- [Официальное расписание занятий](https://rasp.dmami.ru/) — поиск по учебной группе.
- [Экзамены и зачёты](https://rasp.dmami.ru/session) — отдельный раздел.
- [Личный кабинет](https://e.mospolytech.ru/) — расписание и информация по вашей группе.
- [MosRasp](https://mosrasp.ru/) — дополнительный студенческий сервис для быстрого просмотра. При расхождениях сверяйтесь с официальным расписанием и преподавателем.

Проверьте номер группы, дату, тип занятия и корпус. Аудитории с одинаковыми номерами могут находиться на разных площадках.

## Во сколько начинаются пары

Для очной и заочной форм на официальной странице указано:

| Пара | Время       |
| ---- | ----------- |
| 1    | 09:00–10:30 |
| 2    | 10:40–12:10 |
| 3    | 12:20–13:50 |
| 4    | 14:30–16:00 |
| 5    | 16:10–17:40 |
| 6    | 17:50–19:20 |
| 7    | 19:30–21:00 |

Для очно-заочной формы вечерние пары имеют другой график: 18:20–19:40 и 19:50–21:10. Ориентируйтесь на расписание своей группы.

## Каникулы и учебные недели

На [странице расписаний](https://mospolytech.ru/obuchauschimsya/raspisaniya/) опубликованы графики учебного процесса по факультетам. Выбирайте свой факультет, уровень образования и учебный год.
