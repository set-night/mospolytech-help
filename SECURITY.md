# Безопасность

Не публикуй токены, пароли и персональные документы в issues или PR.
Об уязвимости сообщи через [Private vulnerability reporting](https://github.com/set-night/mospolytech-help/security/advisories/new).

## Публикация

- CI для PR, включая форки, не получает Cloudflare secrets. Нет `pull_request_target`.
- Deploy запускается только после успешного CI для push в `main` исходного репозитория.
- Отдельная задача скачивает артефакт конкретного запуска. Не делает checkout, не запускает скрипты проекта; инструмент публикации закреплён по версии.
- Секрет доступен только шагу отправки в Pages в environment `production`.
- Токен Cloudflare: только `Account → Cloudflare Pages → Edit`, только аккаунт проекта. OAuth Wrangler хранится локально, в CI не используется.
- Аккаунт Cloudflare проекта не должен содержать несвязанные production-сервисы: Pages-токен ограничивается аккаунтом, не отдельным проектом.
- Изменения CI, зависимостей и правил безопасности требуют review владельца через CODEOWNERS и защиту `main`.
- Деплой не выполняется из PR. Для форков есть скачиваемая сборка и HTML-отчёт тестов в Actions.

Сейчас сайт статический и не содержит runtime-секретов. При добавлении Pages Functions нужно отдельно определить доступ к данным, переменным и preview-окружению.
