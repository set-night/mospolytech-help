# Поиск и индексация

Главная и каждый вопрос собираются в отдельный HTML: основной ответ, заголовок, описание и источники доступны роботу без JavaScript. Главная сохраняет минималистичный экран; её H1 доступен для экранных дикторов. У категорий свои H1, title и description.

## Что проверяется автоматически

- У каждого адреса в Sitemap — HTTP 200, уникальные title/description, один H1 и canonical на `https://polytech.help`.
- JSON-LD: WebSite, WebPage/CollectionPage, BreadcrumbList; у статей — Article с источниками, авторством сообщества и датой изменения. Связь с университетом не выдаётся за официальный статус.
- `lastmod` и `dateModified` берутся из истории содержимого и шаблонов Git; дата сверки используется для новых файлов или сборки без истории. Дата простой пересборки не подставляется.
- 404 имеет `noindex`; параметры локального поиска и тегов не создают новых канонических страниц. Для Яндекса задан `Clean-param`, отдельные категории доступны по постоянным URL.
- Внутренние связи «сервис → инструкции → источники» проверяются `npm run check:coverage`. Сохранность старого импорта проверяется там же.
- JSON-LD экранирует `<` и не требует ослабления CSP. Проверки находятся в `tests/seo.spec.ts`.

## Уведомление об обновлениях

После успешной публикации отдельная задача без секретов получает публичные Sitemap и `/indexnow.txt`, проверяет домен и отправляет изменённые URL через IndexNow. Уведомление распространяется между участниками протокола, включая Bing и Яндекс. Google получает ссылки через Sitemap и обычный обход.

`indexnow.txt` — публичное подтверждение владения адресами, доступное поисковым роботам. Оно не даёт доступа к Cloudflare, GitHub, публикации или личным аккаунтам. Не используй здесь ключи API и CI.

HTTP 200 означает приём уведомления, 202 — ожидание проверки ключа. Это не подтверждение появления страниц в выдаче. Сбой внешнего IndexNow виден в журнале, но не отменяет уже опубликованный сайт; повторная отправка произойдёт при следующей публикации.

## Контроль владельцем

Позиции и сроки индексации определяют поисковые системы. Для статистики реальных запросов и ручного переобхода владелец может подтвердить `polytech.help` в Google Search Console и Яндекс Вебмастере, затем добавить `https://polytech.help/sitemap.xml`. Ключи и данные чужих аккаунтов сайт не запрашивает.

Не обещаем FAQ-сниппеты или искусственные оценки: Google прекратил показ FAQ rich results с мая 2026 года. Не добавляй ненастоящие рейтинги, авторов и даты публикации.
