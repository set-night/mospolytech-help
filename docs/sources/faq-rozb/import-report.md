# Импорт faq.rozb.pw

- Источник: https://faq.rozb.pw/ («Политех. Выжить и выпуститься»).
- Получено: 29 октября 2026 года, по публичному `sitemap.xml`.
- Найдено и перенесено: **50 из 50 вопросов**, без ошибок загрузки.
- Созданы `src/content/articles/rozb-*.md`; исходные ответы, HTML блоков ответа, ссылки, стадии и предупреждения сохранены в `snapshot.json`.
- Навигационные страницы, скрытые реплики из чатов, счётчики популярности и формы обратной связи не копировались: они не добавляют справочной информации.

## Что изменено

Материал разложен по категориям, ответы преобразованы в Markdown с таблицами и списками, часть формулировок упрощена. Добавлены поисковые теги («общага», «стипуха», «ЛК», «ПД» и другие), исходная атрибуция и все первичные ссылки. Внутренние ссылки на вопросы ведут на новые статьи.

У всех 50 статей статус `needs-review`: 46 страниц исходника с плашкой «По сайту вуза» прямо сообщают, что редактор ещё не подтвердил ответ; ещё 4 страницы помечены черновиками (`exam-passport`, `first-year-start`, `magnetic-pass`, `upload-passport-scan`). Значение `reviewedAt` здесь — дата переноса/редакторской обработки, **не подтверждение всех фактов первоисточником**. Даты приёма 2026 и суммы 2026/27 оставлены с указанием периода и предупреждением; их нельзя автоматически считать условиями следующего года.

## Исправленная ошибка источника

В `masters-admission` исходник утверждал, что после специалитета бюджет возможен, если у выпускника **нет** квалификации «дипломированный специалист». Проверка официального FAQ 29.10.2026 показала обратное: университет указывает возможность бюджета для квалификации «дипломированный специалист» (поступавшие в 2010 году и ранее). В перенесённой статье это исправлено, ссылка дана прямо рядом с утверждением. Оригинальное ошибочное утверждение сохранено только в исходном snapshot для аудита.

Первичная проверка: https://mospolytech.ru/postupayushchim/priem-v-universitet/faq/ . Остальные утверждения не прошли независимую построчную сверку; в частности, суммы стипендий, медицинские требования, налоговые вычеты и условия отсрочки требуют отдельной проверки перед снятием `needs-review`.

## Воспроизведение

Скрипты не нужны для сборки сайта. Они используются только для осознанного повторного импорта:

```sh
uv run --with beautifulsoup4 docs/sources/faq-rozb/import.py
uv run --with beautifulsoup4 --with markdownify docs/sources/faq-rozb/convert.py
```

Повторная конвертация перезаписывает только `rozb-*.md`. Перед запуском сохраните редакторские правки и проверьте diff. Сборка сайта использует закоммиченный Markdown и не обращается к исходному сайту.
